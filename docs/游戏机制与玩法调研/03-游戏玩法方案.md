# 游戏玩法方案

## 1. 玩法不是机制清单

机制是“积木”，玩法是玩家反复做出的行为和决策循环。

例如：

- “获得道具”和“检查是否持有道具”是机制；
- “探索环境找到钥匙，再决定打开哪扇门”才是玩法。

因此，凤翎工坊不能只提供触发器和变量。平台还要提供一层“玩法包”，将资源、规则、界面和默认反馈组合成作者能直接使用的完整循环。

## 2. 平台应支持的玩法包

### A. 调查推理包——首版优先

核心循环：

```text
进入现场 → 观察异常 → 获取线索 → 询问角色
→ 对照矛盾 → 提交推断 → 解锁新区域或结局
```

配套能力：线索库、调查日志、线索门槛、条件对话、推断选择、错误反馈、多个结论。

适用内容：悬疑、刑侦、都市异闻、科幻调查。

### B. 冒险解谜包

核心循环：

```text
探索 → 获得道具 → 识别用途 → 操作机关
→ 改变场景状态 → 到达新区域
```

配套能力：背包、组合或消耗道具、锁门、机关状态、环境变化。

适用内容：密室、古墓、奇幻冒险、机关解谜。

### C. 关系对话包

核心循环：

```text
对话选择 → 关系值或立场变化 → 解锁新话题
→ 角色行为变化 → 进入角色结局
```

配套能力：关系值、隐藏选项、首次/再次对话、角色记忆、角色结局。

适用内容：恋爱、群像、职场、阵营政治。

### D. 目标与倒计时包

核心循环：

```text
获得限时目标 → 选择行动顺序 → 时间或资源消耗
→ 部分任务互斥 → 承担未完成后果
```

配套能力：回合或时间推进、目标列表、失败条件、行动成本、结局判断。

适用内容：生存、灾难、限时营救、时间循环。

首版不建议做战斗、装备数值和经济系统。它们会显著扩大编辑器、AI、平衡性和测试范围，却不能强化当前“小说可视化”的差异化。

## 3. 《07号调查员》的玩法定位

《07号调查员》应该被定义为“限时调查叙事”示例，而不是步行看对白的像素游戏。

### 核心幻想

玩家扮演七天后将被清洗的旧型号调查单元，在例行巡检中寻找“是谁在维护已注销单元、为什么系统记录被抹除”的答案，并决定把证据交给谁。

### 核心循环

```text
选择巡检地点
  ↓
在空间中寻找异常物件或角色
  ↓
获得线索、道具或新的询问话题
  ↓
用道具开启受限区域，用线索逼出不同对话
  ↓
把线索连接成推断
  ↓
解锁新的地点、立场选择和结局
```

### 当前工程已经具备的玩法片段

1. 在监测带调查废弃补给箱，获得“值守密卡”。
2. 在 6 号站使用密卡打开气密门。
3. 在门后发现“第5槽，别断电”的手写标签并获得线索。
4. 进入隔离栏雾区触发环境叙述和“雾的边线从未移动”线索。
5. 与 SE-12 首次对话后设置状态，再次对话时呈现不同内容。
6. 通过收集记录解锁受限章节或区域。

这说明底层已经出现玩法闭环，但目前玩家缺少明确目标、推断步骤和后果反馈，作者也无法通过编辑器创建同类闭环。

### 需要补齐的真正玩法

#### 1. 案件目标

进入章节时明确当前问题，而不是只让玩家四处点击：

```text
主目标：确认谁在为已注销的 SE-12 供电
可选目标：查明“12-OUT”的真实含义
```

#### 2. 线索关联与推断

玩家在调查板上连接 2—3 条线索，选择一个结论：

```text
充电日志为空
+ SE-12 电量 100%
+ 手写“别断电”标签
= 有人在绕过系统维护 SE-12
```

错误组合给出解释但不清空进度；正确推断解锁新的询问话题或区域。这一步把“收集文本”转化为玩家判断。

#### 3. 信息换取

对话选项不只改变一句台词，而要消耗或要求信息：

- 拥有指定线索才能质问；
- 公开证据会降低某角色信任；
- 隐瞒证据可保留秘密路线；
- 不同角色只透露部分事实。

#### 4. 有成本的七天

当前 `countdown` 主要是展示信息，不是实际玩法。若启用倒计时，每次跨区域、完成重大调查或休整才消耗一天；普通走动不消耗时间。

倒计时必须产生选择：七天内无法调查所有支线，玩家决定相信谁、放弃什么。没有行动成本和失败后果时，不应把它宣传为倒计时玩法。

#### 5. 多结局而非单线解锁

建议首个完整案例至少包含：

- 服从结局：提交标准报告，接受清洗；
- 泄密结局：把证据交给秦望；
- 同盟结局：与 SE-12、FS-7800 建立旧单元网络；
- 真相结局：完成关键推断并找到维护者。

结局由线索、关系、关键选择和剩余时间共同决定。

## 4. 玩法模板如何服务创作者

作者选择“调查推理”后，平台自动创建：

- 一个案件目标；
- 三个空线索；
- 一个需要两条线索才能出现的询问选项；
- 一个推断节点；
- 成功和失败两个结局；
- 对应的调查日志 UI。

作者只需要替换角色、文本、线索和条件，而不是从空白规则开始。这才是“制作游戏的平台”相较于通用事件编辑器的产品价值。

## 5. 首版玩法闭环

首版用《07号调查员》验收以下一条完整链路：

```text
补给箱获得密卡
→ 密卡开启气密门
→ 获得手写标签线索
→ 标签 + 空日志 + 满电状态组成推断
→ 解锁质问 SE-12 的选项
→ 对话选择改变“信任”状态
→ 解锁一个新章节或结局
```

同一套编辑器应能让作者从空白项目中重新创建这条链路。前者验收玩家体验，后者验收平台能力。
