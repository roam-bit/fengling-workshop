# 凤翎工坊 WORLDSMITH · 作品说明书（课堂版）

> 把小说变成能走进去的像素世界。这一页就够转述；后面是给想深入的人的附录。

## 第 1 页 · 30 秒讲清楚

**一句话**：一个面向小说创作者的可视化平台——不懂编程的作者，用拖拽 + 对 AI 说人话，把自己的小说做成读者可以**走进去探索**的 2D 像素世界；读者点一个链接、浏览器直接玩，零安装。

**双层结构**：
- 《**07 号调查员**》：可玩的悬疑叙事 demo（2095 年，AI 协同文明 + SCP 风异常区域）——是作者**用自己的平台做出来的样品**（自己吃狗粮）。
- **凤翎工坊编辑器**：做出这个 demo 的工具本体——地图、NPC、对话、触发机制全部可视化配置，还能用自然语言命令它。

**3 个亮点**：
1. **对编辑器说人话**：「把市集大棚放到管理局总部附近」「让陈伯巡逻」——AI 听懂意图，系统自动找合法位置、保证路能走通。
2. **机制卡**：「当 走进某区域 → 如果 持有密卡 → 就 播旁白+记线索」三段式积木，不写代码配出游戏逻辑。
3. **全程 AI 辅助开发**：作者是产品经理、编程小白，一个人 + AI 做完全部——200+ 项自动化检查兜底质量。

**在线试玩**（手机可玩，建议横屏；编辑器请用电脑）：
`https://roam-bit.github.io/fengling-workshop/index.html?play=project`

**本地跑起来（3 步，Mac/Windows 都行）**——这是主要使用方式，完整功能都在本地：
- 唯一前置：**Python 3.8+**（macOS 自带；Windows 从 python.org 或微软商店免费装）。不需要 pip、不需要 node。
```
git clone https://github.com/roam-bit/fengling-workshop.git
cd fengling-workshop
python3 server.py        （Windows 用 python server.py）
```
浏览器开 `http://127.0.0.1:8131` 就是完整版（含编辑器）。
没装 git 的同学：仓库页面 **Code → Download ZIP** 解压后同样跑 `python3 server.py`。

## 附录 A · 读者玩到什么

打开链接 → 澜洲大陆地图（塞尔达式战雾：小说写到哪、地图亮到哪）→ 点发光地点进入现场 → 键盘/点击地面移动，走近 NPC 对话 → 对话里做选择、收集线索进「调查日志」→ 线索攒够，新地点解锁显影 → 找到道具（如值守密卡）打开原本锁着的门。探索 → 发现 → 解锁的循环。

## 附录 B · 创作者怎么用（编辑器）

创作流程 6 步：新建项目（选「起手式」模板：空白 / 调查推理 / 对话抉择——每个都是能直接玩的最小场景）→ 拖拽搭场景（建筑/物件/NPC/传送门所见即所得）→ 表单配对话（分支、条件对话页：「它记得你来过」）→ ⚡机制卡配玩法逻辑 → ▶ 一键试玩 → 📤 发布校验（出生点可达/出口连通，通过才给只读分享链接）。

**⌘ AI 命令**：编辑器 UI 和 AI 命令是**同一套意图级 API 的两个客户端**——鼠标拖是一个遥控器，说人话是另一个。AI 只翻译意图（放什么、在谁附近），坐标搜索、合法性验证、碰撞编译全部归系统。不配 AI key 也有内置规则解析兜底。

## 附录 C · 技术方案（给想深入的人）

| 层 | 技术 | 一句话 |
|---|---|---|
| 游戏房间 | Phaser 3（本地化） | 网格移动/碰撞/y-sort 遮挡/镜头跟随 |
| 世界地图 | 纯 DOM | 高清矢量 HUD + 渐进战雾 |
| 数据 | chapters.json | **单一数据源**：剧情/地图/NPC/对话/机制全在这一个文件 |
| 后端 | server.py（Python 标准库） | 静态服务 + 保存 API + AI 命令解析，零 pip 依赖 |
| 美术管线 | Python + Pillow | AI 生图 → 绿幕抠图 → 32 色量化入库 |

**三个值得讲的设计决策**：
1. **数据驱动**：改剧情/地图/机制 = 改 chapters.json（或用编辑器），不碰代码——这是"不懂编程也能创作"的根。
2. **语义层**：街道/地形是「原始事实」，碰撞层是「编译产物」——从根上消灭 AI 生图导致的"空气墙/楼压街"。
3. **无构建**：没有 npm、没有打包器，clone 下来一行命令就跑——像一本书翻开就能读，不用先组装书架。

**质量保障**：`python3 test/e2e_smoke.py` —— 200+ 项端到端确定性检查（数据完整/碰撞连通/存盘往返/发布门/读者模式），全绿才交付。编程小白靠机器尺子保证质量。

## 附录 D · 给同学：拿去改的姿势

这个项目为"被 AI 修改"做了准备，适合当 vibecoding 练习场：

1. **改内容不用碰代码**：`?edit=area_city` 打开编辑器拖拽改；或直接编辑 chapters.json（台词/NPC/机制卡都在里面）。
2. **用 Codex / Claude Code / Cursor 改代码**：仓库根目录 **AGENTS.md** 是给 AI 工具的项目地图（架构、改法配方、已知坑），AI 工具会自动读取——直接说「加一个会巡逻的 NPC」试试。
3. **改完验证**：跑一遍 `python3 test/e2e_smoke.py`，全绿说明没改坏。
4. 三个上手练习建议：给陈伯加一句台词 → 用机制卡做一个"走近就触发旁白"的点 → 用「调查推理」模板新建一章自己的小场景。

## 附录 E · 局限与下一步（诚实版）

- 在线版是**只读试玩**：编辑器的保存/AI 命令需要本地 server（GitHub Pages 是纯静态托管）——想体验完整编辑器请本地跑。
- 时间线/群像两种创作模式是占位；美术为 AI 生成 + 32 色量化，部分场景仍是线框模式待贴图。
- 下一步方向：小说文档 AI 解析（人物/场景自动抽取）、读者数据看板、更多玩法模板。
